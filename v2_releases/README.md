# Closing the loop from pathogenic variant to gene therapy
## Building a rare disease platform in public

I had the opportunity to present at @Edison Scientific two weeks ago on the culmination an AIxScience Build fellowship that @WorldWide Studios and @Michael Raspuzzi made available.

https://sfaisciencestudio.substack.com/p/recap-for-ai-for-science-fellow-demos

I set out to explore the creation of a BioJARVIS for drug discovery.  In the process, I ended up:

1.  Showing the value of read-only environments to scale agentic inference.  
2.  Showing how we could use these read-only environments to scale the exploration of therapeutic hypothesis space in the context of AMD.
3.  Combine a read only environment along with protein foundational models to create a world model along with a closed loop framework to generate and explore an AAV-based thereapeutics in the context of AMD.
4.  Finally, in collaboration with some rare disease researchers, I created a platform that combined all off these concepts together to create an RL-based platform powered by world models to form hypotheses and AAV-based therapeutics for Duchenne's Muscular Dystrophy.
